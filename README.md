# AnalisisComobilidadCOVID-19
-
Este repositorio contiene un proyecto de análisis exploratorio de datos (EDA) y procesamiento masivo sobre el dataset oficial de datos abiertos de COVID-19 en México. El objetivo principal fue procesar **más de 16 millones de registros** de forma eficiente para identificar patrones de comorbilidad y factores de riesgo asociados a la gravedad de los pacientes.
---

## Objetivo del Proyecto

* **Procesamiento de Alto Rendimiento:** Implementar un pipeline de carga y limpieza de datos utilizando **Polars** para superar las limitaciones de memoria y tiempos de cómputo en entornos en la nube (Google Colab).
* **Análisis Epidemiológico:** Identificar la prevalencia de comorbilidades (diabetes, hipertensión, obesidad, inmunosupresión, etc.) en casos confirmados de COVID-19.
* **Aportación Académica:** Documentar los hallazgos en un artículo de investigación / paper técnico sobre el impacto de las condiciones preexistentes.
